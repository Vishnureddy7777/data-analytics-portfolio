# SafeDrive – Insurance Claim Prediction Using Machine Learning and AutoML

## Project Overview
An analytical machine learning project focused on predicting insurance claims and evaluating different modelling approaches.

## Project Components
- Data preprocessing and exploratory data analysis
- Feature engineering
- Machine learning model building and validation
- AutoML model comparison and versioning
- Model evaluation and risk segmentation
- Business reporting and dashboard analysis

## Tools and Techniques
- Python
- Pandas
- Machine Learning
- AutoML
- Model Evaluation
- Data Visualization

## Important Note
The project is for analytical risk assessment and model evaluation, not for automated underwriting or pricing decisions.
